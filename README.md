# WinCounter — téléchargements

Ce dépôt contient uniquement les **installateurs Windows** de WinCounter, le compteur de win
personnalisable pour streamers TikTok LIVE (compteur, multiplicateur, minuteur, roues,
connexion TikFinity, webhooks).

- **Télécharger la dernière version :** [WinCounter-Setup.exe](https://github.com/lpastou66/win-counter-releases/releases/latest/download/WinCounter-Setup.exe)
- L'appli se met à jour toute seule à partir de ce dépôt.
- Le code source n'est pas public.
